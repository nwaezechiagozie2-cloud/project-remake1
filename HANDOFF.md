4. **Refactored `AgentService` (`app/services/agent_service.py`)**:

5. **Fixed the Local Simulator (`scripts/simulate_chat.py`)**:

## Current State of the Architecture

### Customer AI Flow (Autonomous)
```text
Customer Message → AgentService → ReAct Agent (LLM) 
                                     ├── thinks
                                     ├── calls tools (DB/FAQ)
                                     └── generates final text
```

### Vendor Interaction Flow (Structured)
```text
Vendor clicks "✅ YES" → AgentService → matches 'btn_approve' 
                                     ├── fetches bank details
                                     ├── routes message to Customer
                                     └── updates DB status
```

## Environment Notes
- **Dependencies**: `langchain-openai` was installed. The project relies on OpenAI-compatible APIs (specifically NVIDIA NIM) to support native tool calling.
- **Provider Settings**: Ensure `ACTIVE_LLM_PROVIDER="nvidia"` and a valid `NVIDIA_API_KEY` are present in your `.env`. Gemini tool-calling is not wired up yet, as it requires the native Gemini SDK rather than the OpenAI wrapper.
